# CandleManager

CandleManager is a cross-platform, Rust-based command-line tool designed to install, manage, and switch between different versions of Candle ecosystem products.

It provides a unified interface for managing Candle tools, including CandleVM and CandleC, with support for multiple generations and versions.

## Documentation

For more information, installation instructions, and usage details, visit the [CandleManager documentation](https://candle.nozyx.dev/docs/candlemanager).
